Shipwreck Discovery

A VR diving game set on real wrecks sunk as artificial reefs off Destin, Florida. I work on it full-time at AquaticXR, on gameplay systems and the real-time art pipeline, and I'm credited as a developer on its Steam page alongside Scott Gonnello and Ian McLennan.

Game Developer & 3D Technical Artist · AquaticXR · July 2026 to now · Godot 4, GDScript, OpenXR, Blender

What I do on it

  • Build and test coral growth, planting, placement and collision systems in Godot, and tune the wildlife balance around them.
  • Retopologize coral growth stages and large shipwreck assets, lay out UVs, bake PBR materials and deliver Godot-ready GLB files that hold up on Quest.
  • Build the seafloor critters for the experimental branch: about 40 species, from octopus and mantis shrimp to crabs, lobsters, urchins and sea slugs, each placed by its real Gulf of Mexico habitat, with jointed animation and behaviour that runs cheaply on Quest.
  • Track down VR interaction bugs and write regression tests so the fixes stay fixed.
  • Make the trailers and short videos the studio uses to promote the game.

Lionfish Reef Heroes

A pixel-art arcade game for Android and iOS. Lionfish have taken the reef; you dive in, spear them and bring the reef back across ten ocean habitats.

Team of three at AquaticXR, with Ian McLennan and Scott Gonnello · I built it with ChatGPT Codex writing the code · Godot 4.5 · Coming soon

  • Ten habitats with animated marine life, boss fights and collectible gear.
  • Five assignments based on real marine careers: reef survey, coral nursery, turtle rehab and more.
  • I set up one Godot project that builds for desktop, Android and iPhone, with automated builds for both phones.
  • I wired up store purchases with a server that verifies them.

Sector War

Real-time space strategy in the browser: the pace of an .io game with a slimmed-down grand-strategy layer. You never leave the galaxy view.

My own project · I built it with Claude Opus 5.5 writing the code · TypeScript · Node

  • Three modes, from a 20-minute blitz to a two-hour campaign. AI empires each have a personality; there's diplomacy and a Galactic Council.
  • Online multiplayer for up to eight players over WebSockets, on a deterministic engine.
  • 81 automated tests, including a full bot-vs-bot game, plus a headless soak runner and a Python balance model.
  • The whole game also ships as one 8 MB HTML file that runs offline in any browser.

Music Visualizer

Ten GPU shader worlds that react to every part of whatever's playing: the kick, the snare, the hi-hats, the tempo and the drop. It lives in the Windows tray, and the same shaders run in the browser and a Chrome extension.

My own project · Rust · wgpu / DirectX 12 · WGSL · WebGPU · built with Claude Opus 5.5 writing the code

  • A real-time analyzer splits the music into kick, snare and hi-hat hits, tempo and beat phase, the drop, section energy and even piano notes, and each look gives every signal its own job.
  • Each look is one WGSL shader, about half a millisecond a frame, so it stays full of detail at 4K full screen.
  • A frosted-glass UI drawn on the GPU, a window you can dock anywhere, mouse control, and colours taken from the current song's album art.
  • The same shaders run in a WebGPU web player and a Chrome extension.
