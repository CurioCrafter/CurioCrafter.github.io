CurioMesh: open-source retopology for Blender

Problem. Retopology of dense models and scans is slow manual work.

Approach. Guided, part-by-part retopology with a Rust core that runs on every CPU core.

Result. 79,042 faces to 24,222 quads. A 1.26M-face scan went from 47 minutes to about 5. 46 GitHub stars, 17 releases, ~279 tests in CI, Blender 3.6 to 5.2 on Windows, Linux and macOS.

CurioMesh

Free automatic retopology for Blender. One guided panel turns a dense model or photogrammetry scan into clean quads, part by part, and checks every part against the original with a camera from six sides.

My own project · free and open source (GPLv3) · Python · Blender API · Rust · AI-agent assisted

  • 46 GitHub stars and 17 releases, with about 279 tests and CI that checks the Rust core against the Python reference.
  • Pick what the mesh is for (game asset, animation, subdivision, scan cleanup, sculpt base) and press Start. Each part gets its own face count, and you can redo any single part.
  • A native Rust core does the heavy steps on every CPU core: a 1.26-million-face scan went from 47 minutes to about 5.
  • Game-asset tools: LOD sets, normal and colour baking, kept UV seams, and region retopology for redoing just a face or a hand.
  • 17 releases so far, with zips for every Blender from 3.6 to 5.2 on Windows, Linux and macOS.
  • Also by me: Topology Transitions, guided all-quad edge-loop reductions and expansions.

Music Visualizer

Ten GPU shader worlds that react to every part of whatever's playing: the kick, the snare, the hi-hats, the tempo and the drop. It lives in the Windows tray, and the same shaders run in the browser and a Chrome extension.

My own project · Rust · wgpu / DirectX 12 · WGSL · WebGPU · AI-agent assisted

  • A real-time analyzer splits the music into kick, snare and hi-hat hits, tempo and beat phase, the drop, section energy and even piano notes, and each look gives every signal its own job.
  • Each look is one WGSL shader, about half a millisecond a frame, so it stays full of detail at 4K full screen.
  • A frosted-glass UI drawn on the GPU, a window you can dock anywhere, mouse control, and colours taken from the current song's album art.
  • The same shaders run in a WebGPU web player and a Chrome extension.

Cuprum

A browser studio for robots and the circuit boards that drive them. Describe a robot in one file, and Cuprum lays out and routes its KiCad board, simulates the robot walking or driving on that exact board, writes starter firmware, and packages the board for ordering from JLCPCB.

My own project · AI-agent assisted · TypeScript · Three.js · KiCad · Arduino
